## Project description

This repository contains a four-page, HTML-only student website about the real CROP Barbershop network in Astana. The selected branch is at 80 Uly Dala Avenue. The pages are `index.html`, `services.html`, `booking.html`, and `colophon.html`.

## How to open the site

1. Download or clone the repository.
2. Keep all files and the `images` folder together.
3. Open `index.html` directly in a web browser.
4. Use the navigation links to visit every page.

No installation, web server, CSS, or JavaScript is required.
