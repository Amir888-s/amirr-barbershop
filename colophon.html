How This Website Was Made

Research and structure

This local website was created for Assignment 1 in Introduction to Web Technologies. Public information was checked on CROP’s booking page, Instagram, 2GIS and Yandex Maps on 13 September 2026. The material was organized into four pages. Each page uses a semantic header, navigation area, main content and footer instead of general containers.

The files contain HTML only. There is no <style> element, stylesheet, JavaScript, framework or template. This keeps the structure visible before visual design begins.

Editing and checking

<main>
    <h1>Page title</h1>
    <section>Useful content</section>
</main>

The author can open a file in Visual Studio Code, press Command + S to save, and refresh the browser. A validator should return Document checking completed. No errors or warnings to show. If it reports an error, the author should correct the named line and validate again.

Important choices

A <section> groups one topic, an <article> holds content that can make sense independently, and an <aside> adds related advice. A general <div> appears only around the image group, where no more specific semantic element fits. Relative links let all four files work when the folder is opened directly on another computer.

The final author check must add three original photographs, a signed hand-drawn sketch and an in-person quotation before submission.
